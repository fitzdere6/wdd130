# WDD 130 – Web Fundamentals

Coursework from **WDD 130: Web Fundamentals** at BYU-Idaho.

This repository contains various projects and assignments completed throughout the course while learning the fundamentals of web development. The coursework focused primarily on creating and styling websites using **HTML and CSS**, along with learning the basic principles of responsive and accessible web design.

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## Skills Practiced

- Structuring webpages with semantic HTML
- Styling webpages with CSS
- Creating page layouts
- Responsive design for different screen sizes
- Organizing website files and assets
- Basic web accessibility and usability
- Using Git and GitHub for version control
- Building multi-page websites

## About This Repository

The projects in this repository were completed as individual assignments throughout **WDD 130 at Brigham Young University-Idaho**. They represent my early web development coursework and the foundation I later built upon with JavaScript and more advanced web technologies.
